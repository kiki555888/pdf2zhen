### 硬件加速配置（关键！）

本工具依赖 `llama-cpp-python` 进行推理，**动态库必须与您当前使用的版本（llama_cpp_python-0.3.33-py3-cpu-win_amd64）一致**。在 **与 `PDF2zhen.exe` 同级目录_internal 内替换 `llama_cpp` 文件夹。**



> ### 1.基本说明
>
> - **输入文件夹**：选择包含待翻译 PDF 的目录。
> - **输出文件夹**：翻译完成后的文档保存位置。
> - **API Token**：根据所选解析引擎，填写对应的 Token（MinerU 或 PaddleOCR）。
> - **解析引擎**：选择 MinerU API 或 PaddleOCR API。
> - **翻译模型**：选择 `.gguf` 模型文件路径。
> - **拆分页数**：将大 PDF 拆分为多个小文件，便于处理。
> - **目标语言**：选择翻译目标语言（中文/英语）。
> - **额外格式**：可让 MinerU 额外输出 HTML、DOCX、LaTeX 格式（仅中间结果）。
> - **PDF 合并参数**：设置页面尺寸和边距，用于合并截图或图片为 PDF。
> - **跳过步骤**：若已有解析结果或翻译结果，可跳过相应步骤，节省时间。
>
> ### 2. 操作按钮
>
> - **合并成PDF**：将 `pdfs/` 文件夹中的图片和 PDF 合并为一个 PDF（用于整理截图）。
> - **区域截图**：启动截图工具，可拖拽选择区域并多次截图（保存到 `pdfs/`）。
> - **开始处理**：执行完整的翻译流水线（拆分→解析→预处理→翻译→还原→合并）。
> - **停止**：强制停止当前运行的任务（部分步骤不可中断）。
> - **环境检查**：检测系统环境、依赖包版本和显卡信息。
> - **清理中间文件**：清空 `pdfs/`、`split_results/`、`mineru_results/`、`translated_results/`、`final_output/` 等目录。
> - **高级设置**：调整翻译参数（温度、top_p、术语表、风格等）。
>
> ### 3. 高级设置说明
>
> - **温度（temperature）**：控制随机性，值越低结果越确定，值越高越富有创造力（0.3~2.0）。
> - **Top-p**：核采样阈值，限制生成词汇的概率累计和。
> - **Top-k**：限制候选词汇数量。
> - **重复惩罚（repeat_penalty）**：避免生成重复内容。
> - **术语表**：每行一个对照对，支持 `=`、`->`、Tab 或多个空格分隔，如 `深度学习 = 深度学习`。
> - **翻译风格**：可指定“正式专业”、“简洁明了”等风格。
> - **背景信息**：提供上下文背景，帮助模型更准确翻译。
>
> - **推荐模型**：腾讯混元翻译模型（`Hy-MT2-1.8B-Q4_K_M.gguf`），量化版，推理速度快。
>- **下载地址**：请在官方渠道或 Hugging Face 下载，并放置到 `models/` 目录
> - **额外参数**：deepseek的{"thinking": {"type": "disabled"}}参数,主要是针对模型回话会有思考链的问题。禁止后就可以只要译文了。
